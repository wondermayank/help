FAQ

Common questions

How do I see the prompt behind an image?

Click any image in the gallery. A panel opens showing the full prompt text, the model used, and a button to copy the prompt to your clipboard.

How is new content added to the gallery?

All entries live in a single database file. Adding a new image and prompt only requires appending an entry to that file — the page itself never needs to change.

Can I search for a specific style or model?

Yes. Use the search bar to match against titles, prompt text, tags, and model names, or use the tag chips to filter by style.
